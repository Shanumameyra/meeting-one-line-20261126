Entry for the [make.fun bounty](https://make.fun/bounty/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c): write the single sentence that could have replaced an entire pointless meeting.

## The line

> We already decided this in the email nobody read, so this meeting is just that email with worse lighting and no mute button.

## How it works

`main.py` is deterministic (no network, no randomness). It writes the single line to `/output/entry.txt` (or `entry.txt` beside itself when `/output` does not exist).

```sh
python3 main.py
```
